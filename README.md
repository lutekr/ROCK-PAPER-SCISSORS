# ROCK-PAPER-SCISSORS

A small rock paper scissors game that I built for fun in 2022, while learning web development on my own with The Odin Project (a free online course). It was my first web project.

**Live demo:** https://lutekr.github.io/ROCK-PAPER-SCISSORS/ (works best on a desktop screen)

## How it works
- Press START to begin a new game.
- Choose rock, paper or scissors. The computer picks at random.
- You and the computer each have three hearts. When you lose a round, one of your hearts disappears.
- The first to win three rounds wins the game.

## What I used
- HTML
- CSS: Flexbox layout, keyframe animations (the hearts shake when you lose a round) and a retro pixel font
- JavaScript without libraries: changing the page (DOM), click events and timers for the "typing" text and the blinking cursor

## What I would do differently today
- Remove the old click listeners when a new game starts, so they do not add up.
- Replace the long switch statements with a simple table of which choice beats which.
- Remove a condition in the score check that can never run.
